The language of [[Nachýr]], spoken by the [[Kovold|Kovolds]], [[Lizardfolk]] and [[Serpentfolk]].

The language has many dialects, not all of which are mutually intelligible in spoken form. However, the formal written forms are nigh identical. 

Dialects of Draconic include:
- High Draconic, or Old Draconic, which is supposedly made from the tongues of [[Tiamat]] and [[Vahamut]] themselves. This version of the language is generally counted among the True [[Ancient Languages]].
- Serpentine, the hissing dialect spoken by the [[Serpentfolk]] before the [[Withering Blossoms]].
- Koboldic, the most prevalent dialect, spoken by the [[Kovold|Kovolds]] and [[Lizardfolk]].

A few methods for transcribing Draconic are described [[Transliteration of Draconic|here]].

# Counting
Draconic uses a mixed base 6/base 36 number system.

The numbers from 1-36 are usually expressed using a bijective base six number system, which can be combined into a single symbol, with separate symbols for 0 and 6. 

Larger numbers use a base 36 system, which concatenates the symbols from 0-35.

More details can be found in this description of the [[Draconic Number System]].
