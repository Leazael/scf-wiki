Draconic uses a mixed senary/hexatrigesimal number system.

The "core" senary system has 7 symbols, which are transcribed as $0$, $1$, $2$, $3$, $4$, $5$ and $6$. 

After $6$, the numbers up to and including 12 are obtained by adding a single dot over the symbols, similar to the placement of a vowel, to indicate an increment by 6. In transcription, these are often denoted $\overset{.}1$, $\overset{.}2$, $\overset{.}3$, $\overset{.}4$, $\overset{.}5$, and $\overset{.}6$.

A second dot is added for the numbers up to 18, and a third one for the numbers up to 24. For the numbers up to 30, instead of dots, the vowel 'au' is used instead of the dots. In transcription, this is represented with an overline, e.g., $\overline{1}$. For the numbers up to 36, the vowel 'o' is used, transcribed using a tilde, e.g., $\tilde{2}$,

The numbers 1-36 in their most simple form are given by:

| | | | | | |
|-|-|-|-|-|-|
| $1$ | $2$ | $3$ | $4$ | $5$ | $6$ |
| $\overset{.}{1}$ | $\overset{.}{2}$ | $\overset{.}{3}$ | $\overset{.}{4}$ | $\overset{.}{5}$ | $\overset{.}{6}$ |
| $\overset{..}{1}$ | $\overset{..}{2}$ | $\overset{..}{3}$ | $\overset{..}{4}$ | $\overset{..}{5}$ | $\overset{..}{6}$ |
| $\overset{...}{1}$ | $\overset{...}{2}$ | $\overset{...}{3}$ | $\overset{...}{4}$ | $\overset{...}{5}$ | $\overset{...}{6}$ |
| $\overline{1}$ | $\overline{2}$ | $\overline{3}$ | $\overline{4}$ | $\overline{5}$ | $\overline{6}$ |
| $\tilde{1}$ | $\tilde{2}$ | $\tilde{3}$ | $\tilde{4}$ | $\tilde{5}$ | $\tilde{6} = 10$ |

Higher numbers are constructed by concatenation of the symbols $0$ up to $\tilde{5}$. The character $\tilde{6}$ is often used as a leading digit (or leading digits), if this would result in a shorter character string. (This effectively gives the system properties similar to both regular base 36 and bijective base 36.)
